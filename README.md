# 🎭 Anonymous Telegram Bot

ربات تلگرام برای ارسال پیام‌های ناشناس با قابلیت پاسخ‌دهی ناشناس.

## ویژگی‌ها

- 🔗 **لینک شخصی**: هر کاربر لینک اختصاصی داره که بقیه ازش استفاده می‌کنن
- 📨 **ارسال ناشناس**: متن، عکس، ویدیو، ویس، استیکر، فایل و...
- ↪️ **پاسخ ناشناس**: گیرنده می‌تونه ریپلای کنه بدون اینکه هویتش فاش بشه
- 👀 **تیک دیدم**: اطلاع به فرستنده که پیام خونده شد
- 🚫 **بلاک/آنبلاک**: مدیریت افرادی که نمی‌خوای ازشون پیام بگیری
- ⚠️ **گزارش تخلف**: سیستم گزارش‌دهی به ادمین‌ها
- 🔐 **جوین اجباری**: الزام عضویت در کانال قبل از استفاده
- 📊 **آمار کامل**: آمار کاربران و پیام‌ها
- 🛠 **پنل ادمین**: مدیریت کاربران، گزارش‌ها، تنظیمات و...

## نصب

```bash
cd /var/minis/workspace/anonbot
pip install -r requirements.txt
```

## تنظیمات

فایل `config.py` رو ویرایش کن:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN"  # توکن ربات از @BotFather
ADMIN_IDS = [123456789, 987654321]  # آیدی عددی ادمین‌ها
```

یا از متغیرهای محیطی:

```bash
export ANON_BOT_TOKEN="YOUR_BOT_TOKEN"
```

## اجرا

```bash
python3 bot.py
```

## ساختار پروژه

```
anonbot/
├── bot.py              # نقطه ورود ربات
├── config.py           # تنظیمات
├── core.py             # منطق مشترک (نگهبان‌ها، تحویل پیام)
├── db.py               # لایه دیتابیس SQLite
├── handlers_user.py    # هندلرهای سمت کاربر
├── keyboards.py        # کیبوردها
├── texts.py            # متن‌های ثابت
├── utils.py            # ابزارهای کمکی (تاریخ شمسی، ...)
└── data/               # دیتابیس و لاگ‌ها (auto-created)
```

## دستورات ربات

- `/start` - شروع ربات
- `/cancel` - لغو عملیات جاری
- `/id` - نمایش آیدی عددی
- `/rules` - قوانین ربات
